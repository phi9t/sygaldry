│ Output files                                                                 │
│                                                                              │
│ ${RUNTIME_ROOT}/supervisor_status.json    # latest state snapshot            │
│ (overwritten each poll)                                                      │
│ ${RUNTIME_ROOT}/supervisor_events.jsonl   # append-only event log            │
│                                                                              │
│ Health check functions (pure Python, no LLM)                                 │
│                                                                              │
│ ┌──────────────────────┬───────────────────────────────────────────────────┐ │
│ │       Function       │                     Mechanism                     │ │
│ ├──────────────────────┼───────────────────────────────────────────────────┤ │
│ │ check_temporal()     │ socket.create_connection((host, port), timeout=3) │ │
│ ├──────────────────────┼───────────────────────────────────────────────────┤ │
│ │ check_worker()       │ os.kill(int(worker.pid.read_text()), 0)           │ │
│ ├──────────────────────┼───────────────────────────────────────────────────┤ │
│ │ check_cron_running() │ fcntl.flock(fd, LOCK_EX | LOCK_NB) →              │ │
│ │                      │ BlockingIOError = running                         │ │
│ ├──────────────────────┼───────────────────────────────────────────────────┤ │
│ │ check_heartbeat()    │ os.stat(heartbeat).st_mtime vs time.time()        │ │
│ ├──────────────────────┼───────────────────────────────────────────────────┤ │
│ │ check_last_status()  │ Read last_status.json                             │ │
│ └──────────────────────┴───────────────────────────────────────────────────┘ │
│                                                                              │
│ State machine                                                                │
│                                                                              │
│ States: idle | running | stalled | worker_dead | temporal_dead | fixing |    │
│ error                                                                        │
│                                                                              │
│ Transitions:                                                                 │
│   any        → temporal_dead  when Temporal TCP fails 3 consecutive polls    │
│   any        → worker_dead    when worker.pid process dead while cron lock   │
│ held                                                                         │
│   running    → stalled        when heartbeat age > STALL_SECS                │
│   bad_state  → fixing         when LLM fix launched (cooldown expired, tries │
│  < max)                                                                      │
│   fixing     → idle           when fix complete + re-checks pass             │
│   fixing     → error          when consecutive fix failures >=               │
│ SAIL_MAX_FIX_TRIES                                                           │
│   cron_lock  → running        when flock check shows lock held               │
│   no_lock    → idle           when flock check shows lock free               │
│                                                                              │
│ Main loop pseudocode                                                         │
│                                                                              │
│ while not shutdown_requested:                                                │
│     state, issues = assess_health()                                          │
│     write_status(state, issues)          # supervisor_status.json            │
│     append_event("heartbeat", state)    # supervisor_events.jsonl            │
│                                                                              │
│     if state in ("stalled", "worker_dead", "temporal_dead"):                 │
│         if cooldown_expired() and fix_tries < MAX_FIX_TRIES:                 │
│             launch_llm_fix(state, issues)                                    │
│     elif state == "running":                                                 │
│         log(f"SAIL running — heartbeat age {heartbeat_age:.0f}s")            │
│     elif state == "idle":                                                    │
│         log("SAIL idle (cron not running)")                                  │
│                                                                              │
│     time.sleep(POLL_SECS)                                                    │
│                                                                              │
│ LLM fix invocation                                                           │
│                                                                              │
│ subprocess.run(                                                              │
│     ["claude", "-p", prompt,                                                 │
│      "--allowedTools", "Read,Bash,Edit,Write,Glob,Grep",                     │
│      "--permission-mode", "acceptEdits"],                                    │
│     cwd=REPO_DIR,                                                            │
│     timeout=FIX_TIMEOUT,                                                     │
│ )                                                                            │
│ Context injected: state, heartbeat age, last 50 lines of worker.log,         │
│ last_status.json, Temporal reachable.                                        │
│                                                                              │
│ CLI flags                                                                    │
│                                                                              │
│ --once          poll once and exit (for testing)                             │
│ --poll-secs N   override interval                                            │
│ --stall-secs N  override stall threshold                                     │
│ --no-fix        disable LLM fix (monitor only)                               │
│ --runtime-root  override SAIL_RUNTIME_ROOT                                   │
