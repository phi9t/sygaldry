│ formatting, host-side Python tests |                                         │
│ | L4: Integration (Docker, no GPU) | `verify_multi_repo.sh` | Docker + base  │
│ image | ~30s | Legacy/multi-repo mount layout, env vars, Spack store         │
│ integrity |                                                                  │
│ | L5: Snapshot (Docker, optional GPU) | `verify_snapshot.sh` | Docker +      │
│ snapshot image | ~60s | Baked image self-containment (T1-T7) |               │

│ image + Spack store | ~120s | GPU from external repo, workspace              │
│ isolation/persistence |                                                      │
│ | L8: Infra full (Docker + GPU) | `verify_all.sh` | Docker + GPU + base      │
│ image + Spack store | ~30min | Preflight, image build, Spack install, ML     │
│ validation, uv, logs |                                                       │
