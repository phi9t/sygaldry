* Motivation
:PROPERTIES:
:CUSTOM_ID: motivation
:END:

The current Zephyr container infrastructure is ~1,500 lines of bash across 15+ scripts.
It works, but has accumulated real pain points:

| Pain Point        | Bash Reality                                       | Rust Solution                                       |
|-------------------+----------------------------------------------------+-----------------------------------------------------|
| Silent failures   | =set -euo pipefail= catches some, misses many     | =Result<T, E>= — every failure is typed and handled |
| Config sprawl     | 40+ env vars, =readonly= chains, =${X:-${Y:-def}}= | Struct with =#[derive(Default)]=, layered loading    |
| Argument building | Associative arrays + =printf '%s\n'=               | Builder pattern with typed fields                   |
| Lease management  | Hand-rolled file locking with awk                  | =flock(2)= + serde, atomic writes                   |
| Testing           | =launch_container_test.sh= (fragile)               | =cargo test= with unit + integration tests           |
| Cross-platform    | bash-only, GNU coreutils assumed                   | Single static binary, musl target                   |
| In-container init | Sourcing chains (=spack_init.sh → errors.sh=)      | Same binary, different subcommand                   |

The goal is *one binary* — =zephyr= — that replaces:

- =bin/sygaldry= (host CLI dispatcher)
- =container/launch_container.sh= (launcher core, 630 lines)
- =tools/zephyr_job= (host-side job runner, 265 lines)
- =container/entrypoints/*.sh= (8 entrypoint scripts)
- =container/lib/*.sh= (shared libraries)

** Single Binary, Two Modes

#+begin_example
zephyr (single binary)
├── Host mode (auto-detected: SYGALDRY_IN_CONTAINER != 1)
│   ├── zephyr shell [--repo .] [-- args...]     # Interactive container
│   ├── zephyr run [--repo .] -- <cmd>            # Run command in container
│   ├── zephyr job run|status|tail|stop|health    # Background job management
│   ├── zephyr build [--force]                    # Build Docker image
│   ├── zephyr config show                        # Print effective config
│   ├── zephyr validate [--quick]                 # Run validation suite
│   └── zephyr version                            # Version info
│
└── Container mode (auto-detected: SYGALDRY_IN_CONTAINER == 1)
    ├── zephyr init                               # Full Spack+CUDA init
    ├── zephyr init --spack-only                  # Spack init only
    ├── zephyr init --cuda-only                   # CUDA env setup only
    ├── zephyr gpu-check                          # GPU validation (Torch + JAX)
    ├── zephyr verify-spack                       # Spack package verification
    ├── zephyr uv-install <pkg...>                # UV install with Spack constraints
    ├── zephyr hf-download model|dataset <id>     # HuggingFace download
    └── zephyr entrypoint <name> [-- args...]     # Run a named entrypoint sequence
#+end_example

Mode detection: check =SYGALDRY_IN_CONTAINER= env var. If =1=, container mode.
Same binary is baked into the Docker image AND installed on the host.

** Launcher Flow (=host/launcher.rs=)

Replaces =main()= of =launch_container.sh=:

1. Load config (env + CLI flags + defaults)
2. Detect launch mode (legacy vs multi-repo)
3. Log deprecation warnings for legacy env vars
4. Pre-flight checks (docker, nvidia runtime)
5. Setup host directories (=mkdir -p= for all paths)
6. Write =layout_version.json=
7. Build/check Docker image (per build policy)
8. Detect =spack_baked= label from image
9. Resolve mount paths (=realpath= + =mkdir -p=)
10. Resolve entrypoint container path
11. Acquire lease (if lease mode != off)
12. Build docker args (typed builder)
13. Execute: =docker run <args> <image> <passthrough_args>=
14. Release lease (RAII drop)
15. Exit with docker's exit code

** Docker Argument Builder (=host/docker_args.rs=)

Replaces the associative array + =build_docker_args()= function.
Uses a typed struct with volume mounts, env vars, and GPU config.

Key mounts:
| Host Path                      | Container Path          | Notes                       |
|--------------------------------+-------------------------+-----------------------------|
| =<project>/home=                | =/home/kvothe=           | Per-project                 |
| =<shared>/spack_store=          | =/opt/spack_store=       | 42GB, shared (skip if baked) |
| =<shared>/hf_cache=             | =/opt/hf_cache=          | Shared                      |
| =<shared>/uv_cache=             | =/opt/uv_cache=          | Shared                      |
| =<project>/outputs=             | =/workspace/outputs=     | Per-project                 |
| =<shared>/torch_cache=          | =/opt/torch_cache=       | Shared                      |
| External repo (multi-repo)     | =/workspace/<repo_name>= | Workdir                     |

** Lease Management (=host/lease.rs=)

RAII guard pattern: lease file is removed when =LeaseGuard= drops.

#+begin_src rust
pub struct LeaseGuard { path: PathBuf }
impl Drop for LeaseGuard {
    fn drop(&mut self) { let _ = std::fs::remove_file(&self.path); }
}
#+end_src

Modes: =off= (no lease), =warn= (log conflict), =enforce= (error on conflict).

** Job Runner (=host/job.rs=)

Replaces =tools/zephyr_job=. Five subcommands:

- =run= — spawns detached container, writes PID + JSONL + status files
- =status= — reads latest status file
- =tail= — reads last N lines of JSONL log
- =stop= — sends SIGTERM to PID
- =health= — checks PID liveness + last status

The in-container job wrapper (was base64-encoded bash) becomes
=zephyr job-wrapper --name <name> -- <cmd>=.

:PROPERTIES:
:CUSTOM_ID: container-side

** Spack Init Cascade (=container/spack.rs=)

Replaces =spack_init.sh=. Cascade order preserved:

1. Verify =/opt/spack_src/share/spack/setup-env.sh= exists
2. Add Spack bin to PATH
3. Activate Spack env from candidate list:
   a. =$SYGALDRY_SPACK_ENV=
   b. Current directory (if =spack.yaml= / =spack.lock= present)
   c. =/opt/spack_env/default=
   d. =/opt/spack_env/zephyr=
   e. =$SYGALDRY_ROOT/pkg/zephyr=
4. If no env activated, fall back to view injection (=/opt/spack_store/view=)
5. Setup CUDA (=CUDA_HOME=, =PATH=, =LD_LIBRARY_PATH=)
6. Auto-activate MLSys venv (if =SYGALDRY_MLSYS_ENV= set)

*Key insight:* Spack init modifies the current shell's env. In Rust, we set
=PATH= / =PYTHONPATH= / =LD_LIBRARY_PATH= directly for the view fallback case,
and invoke =python3= as a subprocess.

** GPU Check (=container/gpu_check.rs=)

Embedded Python script validates both Torch CUDA and JAX GPU.
Includes tensor matmul ops to catch ABI/driver mismatches.

** UV Install (=container/uv_install.rs=)

1. Locate Spack Python (=/opt/spack_store/view/bin/python3=)
2. Create venv with =--system-site-packages=
3. Write =.pth= file for Spack view
4. Generate constraints from =spack_owned_packages.conf=
5. Run =uv pip install --constraint <constraints> [--override <nvidia>] <pkgs>=

* Binary Distribution
:PROPERTIES:
:CUSTOM_ID: distribution
:END:

Two paths:

1. *Host install:* =cargo install= from workspace, or pre-built release binary.
   Symlinked to =/usr/local/bin/zephyr=.

2. *Baked into image:* Multi-stage Docker build copies binary into image.
   Available at =/usr/local/bin/zephyr= inside the container.

Cross-compilation:
#+begin_src bash
cargo build --release --target x86_64-unknown-linux-musl
#+end_src

* Testing Strategy
:PROPERTIES:
:CUSTOM_ID: testing
:END:

| Layer       | What                                              | How                                              |
|-------------+---------------------------------------------------+--------------------------------------------------|
| Unit        | Config loading, path resolution, docker args, lease | =cargo test= (no Docker needed)                   |
| Integration | Full launcher flow with real Docker               | =cargo test --features integration= (Docker + GPU) |
| Snapshot    | Verify baked image works                          | =zephyr verify-spack= inside container             |
| E2E         | Multi-repo mode, job runner                       | Shell script exercising full workflow            |

Critical unit test: snapshot docker arg output and compare against bash version.
