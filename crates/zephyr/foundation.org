* Overview

Zephyr is the Rust CLI that replaces the bash-based container infrastructure.
It provides a single binary (~6,400 lines) for both host-side container
orchestration and in-container environment initialization.

** Two-Tier Architecture

- *Docker*: Environment isolation (NVIDIA CUDA 12.9.1 base, user =kvothe= maps to host UID/GID)
- *Spack*: HPC/scientific library management (PyTorch, JAX, NumPy, CUDA, cuDNN)

** Runtime Context Detection

#+begin_example
Host (no container)  ──docker run──▶  Container (SYGALDRY_IN_CONTAINER=1)
       │                                       │
  host/mod.rs::dispatch()             container/mod.rs::dispatch()
#+end_example

| Mechanism | Bash | Rust |
|-----------|------|------|
| Detection | =SYGALDRY_IN_CONTAINER= check | =context.rs::RuntimeContext::detect()= |
| Host dispatch | =container/launch_container.sh= | =host/mod.rs::dispatch()= |
| Container dispatch | entrypoint scripts | =container/mod.rs::dispatch()= |

* Core Features — Host Mode

** Container Launch

The central orchestration pipeline that replaces =launch_container.sh=.

| Step | Bash (launch_container.sh) | Rust (host/launcher.rs:12) |
|------|---------------------------|---------------------------|
| 1. Pre-flight | inline =which docker= + =docker info= | =requirements::check_all()= |
| 2. CUDA check | =nvidia-smi= parsing | =cuda::validate_cuda_version()= |
| 3. Directories | inline =mkdir -p= blocks | =dirs::setup_host_directories()= |
| 4. Image build | inline =docker build= | =image::build_image()= |
| 5. Label read | =docker inspect= | =image::read_image_label()= |
| 6. Entrypoint dir | inline logic | =launcher::resolve_entrypoint_dir()= |
| 7. GPU lease | file-based lock | =lease::acquire()= + =LeaseGuard= (RAII) |
| 8. Docker args | inline arg building | =docker_args::build()= |
| 9. Execute | =docker run= | =Command::new("docker").arg("run")= |
| 10. Lease release | manual cleanup | =Drop= on =LeaseGuard= |

| Policy | Image exists? | Dockerfile newer? | Action |

* Core Features — Container Mode

** Spack Initialization Cascade

The full init sequence replaces =container/lib/spack_init.sh::sygaldry_full_init()=.

| Step | Bash (sygaldry_full_init) | Rust (container/spack.rs:140) |
|------|--------------------------|------------------------------|
| 1. Init spack | =source setup-env.sh= | =init_spack()= (add spack/bin to PATH) |
| 2. Activate env | =spack env activate= | =activate_env()= (candidate list) |
| 3. View fallback | inject view into PATH | =ensure_view_fallback()= |
| 4. CUDA env | inline CUDA_HOME/PATH/LD | =cuda::setup_cuda_env()= |
| 5. MLSys venv | =source venv/activate= | =mlsys_venv::activate()= |

*** Activation Candidate Order

1. =$SYGALDRY_SPACK_ENV=
2. Current directory (if spack.yaml/spack.lock present)
3. =/opt/spack_env/default=
4. =/opt/spack_env/zephyr=
5. =$SYGALDRY_ROOT/pkg/zephyr=

| =GpuValidationFailed= | GPU check script failed |
| =CommandFailed= | subprocess non-zero exit |
| =JobNotFound= | job status/log files missing |
